When each model fit best

Opus 4.8 · build

The workhorse. Costs the most in absolute dollars, but the spend turns into shipped code — 784 edits across 117 files in one 5-hour window, only a third of it sub-agents. When I need features and fixes, this is what delivers.

Sonnet 5 · efficient

The efficient middleweight. For well-scoped, routine work it ships at a fraction of Opus's cost and never comes near the plan ceiling. The value pick when the task is clearly defined. (Illustrative.)

Fable 5 · caution

The credit furnace. 90% of its work was a sub-agent fleet reading and reasoning (88% explore, 5% deliver). It maxed the 5-hour session limit and spilled ~$400 into usage credits — for 166 edits. Most capable at consuming credits, not at shipping what I asked for.

Method. Reconstructed on-device from my Claude Code transcripts (~/.claude/projects/**/*.jsonl). Each card is that model's heaviest single 5-hour window in my history.
